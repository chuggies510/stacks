# My Knowledge Library

A personal source-grounded knowledge library powered by [Stacks](https://github.com/chuggies510/stacks).

## Usage

- Use `stacks:new-stack {name}` to create a topic stack.
- Drop source files in `{stack}/sources/incoming/`.
- Use a compatible Stacks harness to catalog and audit staged sources.
- Use `stacks:lookup "your question"` from any repo to query grounded content.
