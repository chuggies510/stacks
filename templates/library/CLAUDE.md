# Library CLAUDE.md

A knowledge library managed by the stacks plugin: one or more stacks, each with curated
sources and LLM-synthesized topic guides.

## Session start

After `/workspace-toolkit:start`, enumerate the stacks before asking what to work on:

```bash
find . -maxdepth 1 -type d ! -name ".*" ! -name "dev" | sort | while read -r STACK; do
  [ -f "$STACK/STACK.md" ] || continue
  echo "stack=$(basename "$STACK")" \
    "articles=$(find "$STACK/articles" -maxdepth 1 -name '*.md' 2>/dev/null | wc -l | tr -d ' ')" \
    "sources=$(find "$STACK/sources" -type f ! -name .gitkeep ! -path '*/incoming/*' 2>/dev/null | wc -l | tr -d ' ')" \
    "incoming=$(find "$STACK/sources/incoming" -type f ! -name .gitkeep 2>/dev/null | wc -l | tr -d ' ')"
done
```

Then display one line per stack (`{name} — {N} articles, {N} sources filed`, plus
`[INCOMING: N]` when incoming > 0) and close on a single next step derived from state:

- No stacks → `/stacks:new-stack {name}`
- Stack, no articles, no incoming → drop sources in `{stack}/sources/incoming/`
- Incoming sources present → `/stacks:catalog-sources {stack}`
- Articles, no incoming → `/stacks:audit-stack {stack}`

## Conventions

- **Sources are immutable.** Raw material goes in `{stack}/sources/incoming/`;
  catalog-sources files it by origin and synthesizes it into article-per-concept entries.
- **Trash is soft-delete.** `mv` a filed source into `{stack}/sources/trash/` to pull it
  from circulation without losing it. Gitignored, skipped by catalog and audit, recovered
  by moving it back.
- **Articles, chapter files, and `index.md` are LLM-maintained.** Never hand-edit them.
  `index.md` is the routing map `/stacks:lookup` reads, regenerated by catalog-sources.
- **Deep reference is the handbook shelf.** `{stack}/reference/{book}/` holds gated,
  page-cited handbook chapters from `/stacks:ingest-book`. `/stacks:lookup` reads them
  behind the articles: articles are the first-class answer, reference is the shelf behind
  them. Raw PDFs there are local-only. Promote a chapter by copying it into
  `sources/incoming/` and re-cataloging.
- **`log.md` is append-only.** **`STACK.md` is the schema** — edit it to change how the
  stack is curated.
